
## 주제 : Derived State 안티패턴을 제거하는 리팩터링

[실험방법]
1. Derived state 안티패턴 제거전 실행 시간 계산
2. 안티패턴 제거 후 실행 시간 계산

[실험결과]

Before: 상태 변경 -> 1차 렌더링 -> useEffect 실행 -> 두 번째 상태 변경 -> 불필요한 2차 렌더링(Cascade Render) 발생
After: 컴포넌트 재실행 시 최신 스냅샷을 읽어 단 한 번의 렌더링으로 처리

안티패턴 제거 전/후 최대 2.8ms -> 1.1ms 줄었다.  
state로 굳이 생성할 필요없고 가공할수 있는 정보들은 최소한의 state를 운영하여 렌더링 비용을 줄여야한다.
