연구 주제 : React Authentication, Authorization, Cache & Production Architecture

핵심 질문 : 실제 서비스가 되기 위해 개발 환경 외에 어떤 설계가 필요한가?

# 공용 학습 목표
- Authentication과 Authorization을 명확히 구분한다.
- Cookie / Session의 관계를 설명할 수 있다.
- HttpOnly / Secure / SameSite의 목적을 이해한다.
- 인증 확인과 권한 검사를 어느 계층에 둘지 판단한다.
- Proxy가 전체 authorization solution을 대체하지 않는 이유를 이해한다.
- Static / Dynamic / Cached Data의 요구사항을 구분한다.
- Revalidation과 freshness requirement를 연결한다.
- loading / error / not-found 상태를 production UX의 일부로 설계한다.
