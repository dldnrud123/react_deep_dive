
## 주제 : React DevTools Profiler로 render와 commit을 관찰

# 실험방법 

React DevTools의 Profiler 탭에서 기록 시작(파란 버튼)을 누른다.

- 실험 A: [카운트 증가] 버튼 클릭 후 기록 종료 → Flamegraph 차트 확인
- 실험 B: [텍스트 토글] 버튼 클릭 후 기록 종료 → Flamegraph 차트 확인

# 실험결과

부모의 state값이 변경되어 A,B 모두 재랜더링 됨이 확인되었다.
이렇게 되면 각 컴포넌트의 실행이 독립적이지않아 쓸모없는 성능저하게 생김.

각 자식컴포넌트들이 서로 영향을 주지않으려면, 자식 컴포넌트의 값에 react.memo를 적용

(적용샘플)

``` jsx

const SlowComputeChild = memo(function SlowComputeChild({ count }) {
  const startTime = performance.now()
  while (performance.now() - startTime < 30) {
  }

  return (
    <div style={{ border: '2px solid #fd7e14', padding: '10px', margin: '8px 0' }}>
      <strong>SlowComputeChild</strong>
      <p style={{ margin: '4px 0' }}>부모 카운트: {count} (30ms 렌더 연산 포함)</p>
    </div>
  )
})


const MutatingChild = memo(function MutatingChild({ text }) {
  return (
    <div style={{ border: '2px solid #0d6efd', padding: '10px', margin: '8px 0' }}>
      <strong>MutatingChild</strong>
      <p style={{ margin: '4px 0' }}>실제 변경 텍스트: <span style={{ color: '#0d6efd' }}>{text}</span></p>
    </div>
  )
})

```

자식 본인에서 사용하는 props값이 변화되지않으면, 다른 자식 컴포넌트의 연산의 성능저하에 영향을 주지않게 됨.
