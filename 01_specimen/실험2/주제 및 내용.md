
## 주제 : 동일한 UI에서 component type / 위치 / key를 변경하며 state preservation 차이 비교

# 실험방법 : 내부의 input에 내용을 적고 input value값 유지되는지 확인한다.

1. 동일 위치 + 동일 타입 + props만 변경
=> 동일 노드내의 일부 props값만 변경되기때문에 umount는 되지않고 재활용된다

2. Component Type 변경 (Identity 파괴)
=> type값(태그)가 변경되기 때문에 컴포넌트 umount가 일어난다.

3. Render Tree 위치(구조) 변경
=> 트리순서가 변경되게 되면 아예 해당노드를 갈아 끼우기 때문에 unmout된다.

4. 동일 위치 + 동일 타입 + Key만 변경
=> key값이 변경되면 엄격하게 검사되어 동일한 key값이 아닌경우 unmout된다.
