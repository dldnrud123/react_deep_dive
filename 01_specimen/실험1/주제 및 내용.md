
## 주제 : Parent → Child 구조에서 부모 state 변경 시 각 컴포넌트 실행 횟수 기록

부모 컴포넌트에 A,B의 자식 컴포넌트를 두고. 
A와 B에서 리랜더링 되는지 관찰. 

- A 컴포넌트 : 부모에서 변화되는 state를 자식에도 사용할 경우
- B 컴포넌트 : 부모에서 변화되지만 자식에서는 사용안하는 경우 

1. 부모 컴포넌트에서 업데이트 시 A, B가 동일하게 리랜더링됨 
2. B에 react.memo 적용 후, B에서는 리랜더링이 안됨. A는 동일
    → 자식 컴포넌트 자체를 여러 곳에서 독립적으로 방어
3. B를 children props로 부모 밖에서 주입하여 적용, B에서는 리랜더링 안됨. A는 동일 
    → 레이아웃 래퍼로 사용 시
4. B에 useMemo() 사용 시, B에서는 리랜더링 안됨. A는 동일 
    → 레이아웃 래퍼로 사용 시
5. A,B 외의 count 버튼을 따로 독립적으로 두고 카운트 컴포넌트를 따로 생성하여 적용시(State Down), count시 A,B 모두 리랜더링안됨. 
    → 독립적인 기능으로 전체를 재랜더링 할 필요없는 경우, 전역(global)에서 사용할 필요가 없는 요소일 경우.
