핵심 질문 : 이 코드는 어디에서 실행되며, 어떤 결과가 네트워크를 넘어가는가?

# 공용 학습 목표
- Server Component와 Client Component를 execution environment 관점에서 구분한다.
- RSC와 SSR을 서로 다른 개념으로 설명할 수 있다.
- Hydration이 무엇이고 언제 필요한지 설명한다.
- use client가 파일 하나의 실행 위치만 뜻하는 것이 아니라 boundary를 만든다는 점을 이해한다.
- Client Component가 필요한 조건을 판단한다.
- Server Component에서 데이터를 가져오는 장점을 설명한다.
- Streaming / Suspense가 waterfall과 UX에 미치는 영향을 이해한다.
