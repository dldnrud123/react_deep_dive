
## 주제 : Effect로 만든 derived state 제거

[실험방법]
1. derived state로 구성된 검색페이지로 검색 후 콘솔확인.(App1.js)
2. derived state 제거한 뒤 검색 후 콘솔확인.(App2.js)

[실험결과]

1. 검색어 입력(State 변경) 시 1차 렌더링이 발생한 직후, useEffect가 실행되면서 내부의 setFilteredItems가 추가 호출됨.
   이로 인해 하나의 입력 동작에 대해 불필요한 2차 렌더링(리렌더링 2회)이 연속으로 발생하며, 1차와 2차 렌더링 사이에 데이터 불일치 구간이 생김.

2. setQuery로 컴포넌트가 재실행될 때 본문에서 items.filter(...)가 즉시 수행되어 최신 계산 결과가 UI에 바로 반영됨.
   useEffect 오버헤드 없이 단 1회의 렌더링만으로 동기화가 완료되어 렌더링 횟수가 감소하고 코드가 간결해짐.
