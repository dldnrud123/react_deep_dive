
# Pure Rendering / Event Handler / Effect의 역할을 구분한다.

- Pure Rendering : 순수하게 화면구성(jsx)을 위한 부분, sideEffect X
  실행시점 : 컴포넌트 함수 호출 시
  목적 : 화면출력

- Event Handler  : 사용자의 EventTrigger에 의한 동작을 정의하는 부분, 유저가 특정 동작 시
  실행시점 : 사용자가 특정 동작 시 (onClick, onChange 등)
  목적 : 유저 요청에 따른 트랜잭션 수행

- Effect : 외부의 시스템과 동기화를 정의하는 부분
  실행시점 : 컴포넌트가 화면에 다 그려진(Paint) 직후
  목적 : 리액트 상태와 외부 시스템(DOM/API)의 동기화

# Effect를 component lifecycle 대체제가 아닌 Synchronization 관점으로 설명한다.

전통적인 웹은 페이지 새로고침으로 DB 데이터를 새로 받아왔지만, SPA 환경에서는 컴포넌트가 화면에 유지된 채 내부 상태(검색 조건, 페이징)만 바뀐다. 
따라서, useEffect는 마운트 시점 한 번만 실행되는 생명주기 대체제가 아니라, 컴포넌트 내부의 '조회 조건(State)'이 바뀔 때마다 그에 맞는 '외부 DB 데이터'를 지속적으로 일치시키는 동기화 파이프라인으로 접근해야 한다.


# Effect dependency가 필요한 이유를 closure와 연결하여 설명한다.

아래 예시를 보자.

예시)
```jsx
function ChatRoom({ roomId }) {
  useEffect(() => {
    // 소켓에서 메시지가 올 때마다 실행되는 콜백 함수를 등록함
    chatServer.on('message', (msg) => {
      console.log(`[${roomId} 수신] ${msg.text}`);
    });

    return () => chatServer.off('message'); // 채팅방 나가기 
  }, []); //
}
```
roomId가 처음 'first' -> 'second'로 변경된 후 'hi'라는 채팅방 메시지가 수신되면 콘솔에 어떻게 찍힐까? 
first 수신 : hi 라고 찍힐것이다 

(정리)
리액트의 모든 Hook과 함수는 특정 렌더링 시점의 '불변 스냅샷'을 바라본다.
의존성 배열(deps)은 컴포넌트의 데이터가 바뀌어 새로운 스냅샷이 생성되었을 때, 스냅샷을 최신화하도록 지시하는 스냅샷 동기화 장치다.

# Stale Closure를 재현하고 해결할 수 있다.

(문제코드)
```jsx
function StopWatch() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    const timer = setInterval(() => {
      // 1회차 스냅샷(count = 0)만 영원히 바라봄
      setCount(count + 1);
    }, 1000);

    return () => clearInterval(timer);
  }, []); // 빈 배열: 마운트 시점 스냅샷에 갇힘

  return <h1>{count}초</h1>;
}
```

(수정코드1) 
```jsx
function StopWatch() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    const timer = setInterval(() => {
      setCount(count + 1);
    }, 1000);

    return () => clearInterval(timer);
  }, [count]); // count가 바뀔 때마다 타이머를 갈아끼움 (비효율적)

  return <h1>{count}초</h1>;
}
```

(수정코드2)
```jsx
function StopWatch() {
  const [count, setCount] = useState(0);

// 마운트 시점에 타이머를 딱 "1번만" 켬
  useEffect(() => {
    const timer = setInterval(() => {
      // 리액트 내부 큐에 "기존 최신 값에 +1 해라"는 함수만 던짐
      setCount((prev) => prev + 1);
    }, 1000);

    // 컴포넌트가 화면에서 사라질 때 딱 "1번만" 타이머를 끔
    return () => clearInterval(timer);
  }, []); 

  return <h1>{count}초</h1>;
}
```

(수정코드3)
```jsx
function StopWatch() {
  const [count, setCount] = useState(0);
  const countRef = useRef(0); // 스냅샷에 묶이지 않는 고정 메모리 주소 확보

  useEffect(() => {
    const timer = setInterval(() => {
      // 1. 메모리 주소(current)의 값을 직접 1 증가
      countRef.current += 1;
      // 2. 최신 Ref 값을 읽어서 화면 리렌더링 트리거
      setCount(countRef.current);
    }, 1000);

    return () => clearInterval(timer);
  }, []); // 타이머는 1번만 켜지고 유지됨

  return <h1>{count}초</h1>;
}
```
